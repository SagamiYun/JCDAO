## 💰 Step 2: 领取测试币 / Get Test Tokens / テストトークンを取得

### 使用 Faucet 领取 POL / Get POL from Faucet / FaucetからPOLを取得

| 🇨🇳 中文 | 🇺🇸 English | 🇯🇵 日本語 |
|---------|-------------|-----------|
| 测试币是免费的，用于支付 Gas 费 | Test tokens are free, used to pay Gas fees | テストトークンは無料で、Gas料金の支払いに使用 |

#### Faucet 链接 / Faucet Links / Faucetリンク

| Faucet | URL | 备注 |
|--------|-----|------|
| **Polygon Faucet (官方)** | https://faucet.polygon.technology | 推荐首选 |
| **Alchemy Faucet** | https://www.alchemy.com/faucets/polygon-amoy | 需要注册账户 |
| **QuickNode Faucet** | https://faucet.quicknode.com/polygon/amoy | 备选方案 |

#### 操作步骤 / Steps / 手順

**🇨🇳 中文:**
1. 访问上方任一 Faucet 网站
2. 连接你的钱包，或粘贴你的钱包地址
3. 点击「Request」或「Claim」按钮
4. 等待几秒钟，测试 POL 将到账
5. 在 MetaMask 确认余额 (通常 0.1 - 0.5 POL)

**🇺🇸 English:**
1. Visit any Faucet website above
2. Connect your wallet or paste your wallet address
3. Click the "Request" or "Claim" button
4. Wait a few seconds, test POL will arrive
5. Confirm balance in MetaMask (usually 0.1 - 0.5 POL)

**🇯🇵 日本語:**
1. 上記のFaucetサイトにアクセス
2. ウォレットを接続するか、ウォレットアドレスを貼り付ける
3. 「Request」または「Claim」ボタンをクリック
4. 数秒待つと、テストPOLが届きます
5. MetaMaskで残高を確認（通常0.1〜0.5 POL）

> 💡 **提示 / Tip / ヒント**: 如果一个 Faucet 不工作，请尝试其他的！/ If one Faucet doesn't work, try another! / 1つのFaucetが動作しない場合は、他を試してください！

## 🎫 Step 3: Mint SBT 会员凭证 / Mint SBT Membership / SBT会員証明をMint

### 什么是 SBT? / What is SBT? / SBTとは？

| 🇨🇳 中文 | 🇺🇸 English | 🇯🇵 日本語 |
|---------|-------------|-----------|
| SBT (Soulbound Token) 是**不可转让**的 NFT | SBT (Soulbound Token) is a **non-transferable** NFT | SBT（ソウルバウンドトークン）は**譲渡不可能な**NFT |
| 它代表你的 JCDAO 会员身份 | It represents your JCDAO membership | JCDAOの会員資格を表します |
| 一个钱包只能拥有一个 SBT | One wallet can only hold one SBT | 1つのウォレットには1つのSBTのみ |

### Mint 操作步骤 / Minting Steps / Mint手順

#### 访问 DApp / Visit DApp / DAppにアクセス

```
🔗 JCDAO DApp: https://jcdao.vercel.app
```

#### 操作流程 / Workflow / ワークフロー

**🇨🇳 中文:**
1. 访问 JCDAO 官方 DApp
2. 点击「Connect Wallet」连接 MetaMask
3. 确保网络切换到 **Polygon Amoy Testnet**
4. 在首页找到「Mint Membership SBT」按钮
5. 点击后，MetaMask 弹窗确认交易
6. 确认 Gas 费用 (测试网免费，仅消耗少量测试 POL)
7. 等待交易确认 (约 5-15 秒)
8. 🎉 恭喜！你现在是 JCDAO 会员了！

**🇺🇸 English:**
1. Visit the JCDAO official DApp
2. Click "Connect Wallet" to connect MetaMask
3. Ensure network is switched to **Polygon Amoy Testnet**
4. Find the "Mint Membership SBT" button on the homepage
5. After clicking, MetaMask popup will ask for transaction confirmation
6. Confirm Gas fees (testnet is free, only consumes small amount of test POL)
7. Wait for transaction confirmation (~5-15 seconds)
8. 🎉 Congratulations! You are now a JCDAO member!

**🇯🇵 日本語:**
1. JCDAO公式DAppにアクセス
2. 「Connect Wallet」をクリックしてMetaMaskを接続
3. ネットワークが**Polygon Amoy Testnet**になっていることを確認
4. ホームページで「Mint Membership SBT」ボタンを見つける
5. クリック後、MetaMaskのポップアップでトランザクション確認
6. Gas料金を確認（テストネットは無料、少量のテストPOLを消費）
7. トランザクション確認を待つ（約5〜15秒）
8. 🎉 おめでとうございます！JCDAOメンバーになりました！

### 验证 SBT / Verify SBT / SBTを確認

| 方法 | 步骤 |
|------|------|
| **DApp 内确认** | 页面会显示「Member」状态 |
| **区块浏览器** | 访问 `amoy.polygonscan.com` 搜索你的地址 |
| **OpenSea (测试网)** | 访问 `testnets.opensea.io` 连接钱包查看 |

## ✅ Step 4: Discord 身份验证 / Discord Verification / Discord認証

### 加入 Discord / Join Discord / Discordに参加

```
🔗 JCDAO Discord: https://discord.gg/jcdao
```

### 使用 Guild.xyz 验证 / Verify with Guild.xyz / Guild.xyzで認証

**🇨🇳 中文:**
1. 加入 JCDAO Discord 服务器
2. 前往 `#🔗-verify` 频道
3. 点击 Guild.xyz 验证按钮
4. 按提示连接你的钱包 (使用 Mint 过 SBT 的同一钱包)
5. Guild.xyz 将自动检测你的 SBT
6. 验证成功后，你将自动获得 `Member` 角色
7. 现在你可以访问所有会员专属频道了！

**🇺🇸 English:**
1. Join the JCDAO Discord server
2. Go to the `#🔗-verify` channel
3. Click the Guild.xyz verification button
4. Follow prompts to connect your wallet (use the same wallet that minted SBT)
5. Guild.xyz will automatically detect your SBT
6. After successful verification, you'll receive the `Member` role automatically
7. Now you can access all member-only channels!

**🇯🇵 日本語:**
1. JCDAO Discordサーバーに参加
2. `#🔗-verify` チャンネルに移動
3. Guild.xyz認証ボタンをクリック
4. プロンプトに従ってウォレットを接続（SBTをMintした同じウォレットを使用）
5. Guild.xyzが自動的にSBTを検出
6. 認証成功後、`Member`ロールが自動的に付与されます
7. これでメンバー専用チャンネルにアクセスできます！

### 验证后权限 / Permissions After Verification / 認証後の権限

| 角色 | 要求 | 可访问频道 |
|------|------|-----------|
| `Visitor` | 无 | 公共频道 |
| `Member` | 持有 SBT | 会员专属频道 |
| `Whale` | 持有 ≥100 JCD | 治理频道 |
